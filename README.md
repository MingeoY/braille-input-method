# 13键盲文输入法

## 📖 项目简介

13键盲文输入法是一款基于Web的多语言盲文输入解决方案，通过创新的13键键盘布局实现高效的盲文输入，支持多种语言的实时转换显示。

## 6点盲文与13键映射

### 🔍 盲文结构
6点盲文由2列3行盲文点位构成，包含空方(⠀)共64个盲符，按照规律分为5行：
- 第一行的3、6点位均为空，
- 第二行在第一行的基础上增加3点位，
- 第三行在第一行的基础上增加3、6点位，
- 第四行在第五行的基础上增加6点位，
- 第五行将第一行由1、2、4、5点位整体下移至2、3、5、6点位（空方下移不变）。

### ⌨️ 键盘布局（5×3 新版）

根据上述盲文排列方式，可将其映射到13键键盘上，通过点击、向左、向上、向右、向下滑动实现行的选择。。效果类似日语12键输入法通过点击和滑动实现“五十音图”的输入方式。
新版布局采用左右对称的5列×3行排列（增加“盲文/明文键盘模式切换键”和“回车键与光标移动控制”）构成5×3键盘，便于记忆和盲操。各键支持 **点击（中央字符）** 和 **向四个方向滑动（左/上/右/下）** 输入不同的盲符。

## 🌐 多语言输入功能

### ✨ 核心特性
- **无需切换输入法**：通过盲文中介，同时显示多种语言字符
- **实时转换**：输入盲文即时转换为各语言文本
- **多语言支持**：世界语、汉语、英语、法语、俄语等
- **灵活配置（待完善）**：最多支持10种语言同时显示

### 界面布局

| 键盘输入               | 文本输出                       |
|-----------------------|--------------------------------|
| 5×3键盘               | 盲文显示框(复制、删除、清空)      |
| 输入方式介绍和操作演示  | 语种1显示框(语音提示、复制) |
| 盲文键盘示意图         | 语种2显示框(复制)          |
|                       | 添加更多语种(最多10个)          |

各语种显示框由标题、文本框、复制键组成，盲文显示框还包括删除键和清空键。

具体到各语种显示，如果某个盲符暂无对应的字符，就在语种显示框中用红色盲符显示。

默认状态不出现语种显示框，用户可选择增加语种、移除语种框或调换语种顺序，添加的语种可重复，但最多同时显示10个。

键盘显示键：按下盲符时，除了显示当前输入的盲符外，还应显示该盲符在语种1中代表的字符。键盘13键在中央和四周显示点击和滑动输入的盲符在语种1中的代表字符，按下时对应方向的字符放大。

## 📝 技术特性

### 🎯 使用流程

1. **选择语种**：通过“添加语种”按钮选择需要显示的语种（最多10个），默认已包含全部7种。
2. **切换模式**：点击“模式切换键”在盲文/明文间切换。
3. **输入盲文**：点击或滑动键盘按键，盲文将显示在盲文框中。
4. **查看转换结果**：下方各语种框实时显示对应的文字（组合则显示组合结果，否则显示盲符）。
5. **语音提示**：开启语音后，每次按键会播报对应盲符的提示音（支持汉语、英语、俄语、日语、西班牙语）。
6. **调整排序**：拖拽语种框可改变顺序，影响键盘显示和语音语种。
7. **复制/清空**：每个框均提供复制按钮，盲文框额外提供删除和清空功能。

### 📁 使用说明

1. **选择语言**：点击"添加语种"选择需要的语言
2. **开始输入**：通过点击或滑动键盘输入盲文
3. **查看结果**：各语言显示框实时显示转换结果
4. **管理内容**：使用复制、删除、清空功能管理文本
5. **调整界面**：拖拽调整语言顺序或输入区域宽度
6. **数据扩展**：所有语种映射数据均定义在 `brailleMaps` 对象中，每个语种包含以下字段。如需添加新语种，只需按照相同结构扩展即可。
- `name`：显示名称。
- `displayChars`：键盘明文模式显示的字符。
- 单字符映射：用于文本输出（无组合时）。
- `comboMap`：组合映射（键为两盲符，值为替换结果）。
- `voicePrompts`：语音提示文本。
7. **部署要求**
- 现代浏览器支持（Chrome、Firefox、Safari、Edge）
- 支持Web Speech API（语音功能）
- 支持Clipboard API（复制功能）
- 响应式设计，支持桌面和移动设备

### 🔗 使用场景

- 盲文学习者对照练习。
- 多语种文本快速输入与对照。
- 辅助视障人士进行多语言输入（配合屏幕阅读器）。
